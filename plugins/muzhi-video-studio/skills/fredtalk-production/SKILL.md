# FredTalk 原生讲解

这是工作室的独立风格入口。先读本片HANDOFF、确认稿、原声/字幕和风格锁。未定稿回内容入口；未选风格回 `../video-production/SKILL.md` 给选择。用户已点名或本片已锁定时不重复问。改变旧风格需用户明确决定，不因插件更新迁移旧项目。

## 先核本机，不猜已有环境

本包不分发FredTalk源库、依赖、私人媒体或账号。按 [准备与调用](references/setup.md) 显式指定上游目录和本片独立Remotion工程。从当前插件根运行 `python scripts/fredtalk_bridge.py status`；它只读本机文件，不下载、安装、生成或写锁。

有效源库只能证明可进入规划。检查结果分别报告 `renderEnvironment`；依赖文件存在也不是成功渲染或视听通过。缺源码、组件、运行依赖时报告具体缺项，不建空目录冒充安装，不换风格继续交假结果。

新项目在用户选择后，用 `scripts/style_registry.py select --project <本片目录> --style fredtalk-native --mode production --reason <真实选择依据> --new-project` 记录。既有项目不得假装新项目；不能覆盖原锁。FredTalk自己的Manifest和本项目状态保持一致，不另造一条并行时间线。

## 从语义到画面

1. 保留原稿和本人原声，复用实际SRT/逐字时间。需修改录音时按本片授权处理新副本；AI配音必须另有明确授权。
2. 从桥接返回的路径完整读上游 `fred-remotion-output/SKILL.md`，再按阶段读取必要参考。每段先写观众问题、对象与可见变化，保住否定、条件、年份、数字和对象，再检索准确组件。候选要实际看，不只贴编号。
3. 选定后保留可辨认的原生动作关系和准确kit参数，再换成本片文字、媒体、数量、时序。允许有来源的场景改编，不照抄上一条样片，不退成静态大字页。
4. 交导演规划和真实关键帧：原话/时间、参考组件、可见动作、证据、阅读窗口和相邻交接。用户确认后再推进相应制作。明确直出授权只影响该片等待步骤，不冒充用户已经看过，也不取消内部检查。
5. 在独立Remotion项目实施，镜头使用局部时钟，原声和字幕沿同一全局时钟。官方证据使用准确原件或明确标注的解释排版，不能用生成图伪造截图、分数或学校政策。
6. 运行实际可用的来源、时钟、关键帧、动态及最终文件检查，逐镜和整片核效果。具体边界见 [质量检查](references/quality.md)。原版某工具不支持当前系统或未公开时如实列缺口，不伪造PASS或改校验器放行。

## 哪些默认不继承

沿用本片用户的品牌、声音、素材权利和输出规格。不要插入Fred的私人广告/过渡配音、私人BGM、人物和品牌，不自动升4K60、云端渲染或扩大费用。此风格已做过1080p横屏样片；竖屏需重新布局和真实关键帧，不能缩小横版后宣称验证完成。

所选上游源码只读，新导演代码、媒体和输出留本片项目；不把它复制进其他产线，不使用其他风格的旧批量命令代替FredTalk原生流程。原图生渠道、配乐、费用和发布边界仍有效；需要时按本片选择，不强迫每个镜头使用生成模型。

最终提供真实可播放文件、规格和未验项；用户认可、技术通过和主观视听分别记录。未获明确发布授权不对外上传。未改的旧项目与产线保持原样。
