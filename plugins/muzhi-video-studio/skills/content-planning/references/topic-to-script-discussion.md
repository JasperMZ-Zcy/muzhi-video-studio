# 从选题讨论到确认口播

本入口可从一个想法、一条已选题目或现有草稿开始。先核本轮目标、原项目卡和已有复盘/知识/事实；区分可核事实、牧之已定判断、暂定创意。用户只要讨论时，不自动开正式稿、拍摄或发布；已确认稿只做用户明确指定的局部修改。

先用人话提出本片最有用的方向：谁在什么处境下会看、准备在哪个平台表达、要回应哪一个真实疑问、牧之的核心判断及适用条件、观众看完能做的动作。可讨论标题、开头、段落推进、笑点、情绪、转化和画风方向；这些随本片需要取舍，不是必须填满的表格。给出有根据的推荐，确有实质分歧时才说明少量备选和代价。已有答案直接用；会改变文案的一个关键决定未定时，依赖顺序只问当前最重要的一件。

具体学校、专业、年份、数字、名额、政策或具名案例必须核相应当年官方原件与对象；缺证据时保留待核，不编具名学生、成绩、咨询经历或学校事实。观点、方法与情绪陪伴稿没有这些具名事实时不因而卡住。内容表达要让学生听懂判断、条件和下一步，保留牧之明确的态度、自然幽默与情绪，不把一条历史留存线索扩成所有题目的固定禁令。

当本轮已授权写稿，直接完成一份可口播初稿，再做必要的人话与事实收口。初稿和收口是工作动作，不限制牧之的反馈轮数；每次反馈按影响范围修改，保持未被否定的判断与句子。结构按本片理解和情绪节奏组织，不固定为“反差—方法—互动”，也不按镜头、字幕或预想时长删条件。确认稿逐字锁定；若后来发现事实错误，标出原句、依据与替代建议，请牧之确认后再改。

在原项目卡或稿件说明中保留最小交接：确认稿版本及确认依据、本片受众与平台、核心判断/条件/反例、事实来源和待核处、语气及画风方向、导演必须帮助观众看懂的关系。运营复盘只引本条真正相关的经验；交给制作后仍由原项目承载状态和反馈，不另造知识库或第二份正式文案。
