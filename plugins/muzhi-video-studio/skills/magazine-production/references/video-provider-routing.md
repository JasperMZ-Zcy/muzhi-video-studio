# 图生视频渠道可切换，合成合同不变

## 每条新片由品牌选

本条涉及图生视频而尚无明确选择时，在第一批提交/生成包之前只问一次：

> 这条图生视频你想用哪个渠道？本地ComfyUI/MiniMax-H3可在你配置好工作流后运行；WAN、MiniMax可走已配置的API；Google Flow我给你首帧和提示词，你手动生成。也可以指定一个新平台。

用户已经在当前任务指定平台，就直接登记，不重复问“确认用这个吗”。继续同一条片沿用本条选择，不从旧项目或插件默认偏好猜。下一条新片重新问，不能把上一片的Google Flow或MiniMax当永久默认。

每次用户明确换平台，按新的选择处理尚未提交的镜头，不强迫切回旧平台。新选项不必修改整条产线或重新讨论画风。

## 四种内置入口

| 渠道 | 交付方式 | 不可擅自改成 |
| --- | --- | --- |
| 本地H3 | 调用使用者本机已安装的ComfyUI/MiniMax-H3 V2工作流；先预检资源和模型，再按项目授权运行，取回后独立审动态 | 把“本机有插件”说成“人人都有模型”、自动占用GPU或失败后付费转云端 |
| WAN | 使用本机已配置的API能力；现有本地适配器若封装API可复用，保留真实任务ID/费用/文件回执 | 未经要求转到网页手工点击，或重新索要已有凭证 |
| MiniMax | 使用本机已配置的API适配器，核可用模型与首帧/时长参数 | 自动换成别的供应商或多生成收费变体 |
| Google Flow | 代理生成/整理首帧与专用提示词，同层按镜号交手动包；品牌生成后回传编号视频 | 代理自行提交Google任务或改用另一个自动API |

选择平台和授权费用是两件事。有既有有效预算就按范围做，缺金额或新增收费不能自行猜；不要重复问用户已经确认的费用。凭证只使用工作区外已有秘密区/工具连接，不写入插件、项目或台账。

## 临时接新平台

先确认它是“已配置API”还是“手动生成包”，以及必要时用户需要提供的工具连接/本地配置位置。注册到本项目，不自动成为全局默认。若用户明确以后都可选，再升级插件渠道目录。

新API适配器至少核对首帧输入方式、模型/时长/比例、任务返回、状态续查、下载方式、费用单位和失败恢复。`tool_ref`只是指向实际工具的名字，不是可以任意执行的命令。注册成功不等于API验证通过，不能拿未验证的新平台直接批量扣费。

新手动平台至少核对支持的时长、比例、首尾帧方式与提示词规则；沿用同一套已批准视觉源，生成对应平台操作包。平台没法满足某镜所需时长，就提前设计续接，不改录音长度。

## 选择与变化留痕

插件脚本`provider_router.py`负责本项目渠道目录与选择记录；不触碰凭证，不执行API。先运行`--help`查看实际参数。

```text
python <ROOT>/scripts/provider_router.py status --project <PROJECT>
python <ROOT>/scripts/provider_router.py list --project <PROJECT>
python <ROOT>/scripts/provider_router.py select --project <PROJECT> --provider google-flow --quote "这次用Google Flow，我手动生成"
```

具体注册/验证按脚本help。无选择返回needs_user_choice=true；不得伪造quote来跳过。切换只针对future_unsubmitted，台账已提交的旧任务仍用原供应商/原jobID续查。旧任务不因换平台被当成没花过钱，新任务仍经generation_ledger预算与去重。

## 与后期解耦

所有供应商最后都交同一类镜头清单，必须保留：

- 镜号、来源平台、原任务ID或manual标记；
- 项目内原视频与SHA；
- 实测时长、宽高、帧率、音轨情况；
- 可用源起点/时长、计划放置时码、动作地标；
- 源声音是否已经去除、实际采用与检查结论。

不得由JSON猜媒体属性。原件入库后先按实际文件探测，再生成统一的剪辑输入；原视频保留。`provider_router validate-delivery`验证供应商无关字段与文件，`production_runner media-audit`/原动态时长校验再做实测与内容检查。

合成只读已经核验的本地视频、时码、画幅与声音，不根据source_provider换一套剪辑逻辑。WAN第1镜、Flow第2镜、MiniMax第3镜可以混合，但必须同一design，维持人物/道具/画风和绝对口播母钟；来源差异记录在manifest，不传染到字幕、混音和品牌规则。

原始素材带音轨时source_audio_removed只能为false；去音轨副本实际完成并探测后才写true。正式合成禁止混入供应商音轨，不能改一个布尔值就说去掉了声音。视频QC、字幕与音频QA不因换供应商降级。

## 原因明确的停点

只在真实缺少渠道选择、费用授权、必要连接或某镜无法覆盖时长时问具体问题。模型暂时失败先续查原任务；缺供应能力则保留已有图/提示词/已通过视频并报告，不重做整条片子，也不把平台更换当作全片风格重启。
