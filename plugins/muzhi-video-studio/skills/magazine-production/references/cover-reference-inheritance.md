# 批准封面基准的继承

用户明确表示“这套封面以后固定使用”时，把它保存为该品牌的默认，不重新询问已确认的设计。区分单次改图与长期偏好，不把某品牌的审美变成所有用户的强制标准。

基准应包含实际参考图及哈希、批准原话、适用品牌、标题区域和层级、配色与材质、平台比例，以及允许每条变化的内容。下次制作必须打开实际图比较，不能只凭描述重建。

例如一套已批准的校园纸感封面可以固定大字居中、两行粗重标题、撕纸底、墨蓝/奶油/砖红对比、人物不遮脸，同时让当条标题和相关场景随主题改变。示例标题不能成为所有新题的填空模板，也不保证任何设计必然获得流量。

只改几个字时，限定在对应文字、必要字号与位置；不要换背景、角色或其他平台封面。标题应完整落在安全边距内，缩略图可读，避开人物眼睛和主表情。检查人物手臂数量、手掌方向、手机正反面和道具接触，不把生成成功当成美术通过。

这类基准只约束封面，不自动改视频风格或时间线；已批准旧封面不自动批量迁移。新用户明确指令优先。真实品牌参考图、私人配置只进入用户授权的本地或私有包；公开示例需要单独核对分享授权。
