# 档案电流拼贴：参考片归纳的可选视觉语法

## 什么时候读取

只有用户明确选择“芯片解说那种拼贴风”“档案电流拼贴”，或当前新项目`design.md`已选择类似路线时读取。这是原杂志插画插件阶段保存的参考片研究；现已独立成为`video-production`入口中的可选风格，实际制作先按新风格目录和项目锁走。它不是新的`visual_route`枚举，也不覆盖已锁定的画风、封面、口播、字幕和旧项目素材。用户只让分析参考片时，不据此启动付费生成或正式时间线。

来源是一条用户提供的约87秒手机录屏。可连续分析的芯片解说约2.65—77.85秒；末尾有暂停控件和另一个视频，不能当作原片结尾。源片画面自称AI生成；下列是**从结果像素归纳的制作方法**，不是对原作者软件/模型的确认。原片截图、人物、Logo、书封与片段音轨不随插件分发。插件原创应用样图见[考研课时换算风格母图](../../../assets/style-boards/archival-current-education-hero.png)；它只是视觉方向，不是已过成片验收的独立图层镜头。

**动态验收边界**：牧之2026-09-24指出，静态风格母图上叠几个字卡或用页面按钮切换，不能代表参考片的连续动画。现已有本机第二轮原生动态试镜，并按牧之“不吹毛求疵”的标准接受为风格方向；约0.5秒金线早于约3.5秒按表是已知单镜瑕疵。以后若研究新风格或新动作，仍须拿真实视频看首/中/尾与动作过程，不能用首尾帧、手动生成包或8秒光流副本冒充动态验收。

## 一句话定位

深蓝档案舞台＋写实器物与剪报层＋纸张接触阴影＋有起终点的暖金关系线＋很少量冲突红。真正的关键不是材质，而是**把口播中的动词变成看得见的因果动作**。一座语义场景承接数句口播，内部发生递进；场景结束时旧层退场，留下一个物件或运动方向接下一场。

## 从口播到镜头：先编译，再备素材

每个可理解画面段在既有导演板/施工单内写清：

`原话与真实时码 → 观众新增的认识 → 第一眼物件 → 主动词 → 谁作用于谁 → 物件如何响应 → 准确文字/证据承载 → 最后看见的结果 → 接下段的物件/光路/声音 → 视觉路线与资产来源`。

先试把“替代、走出、押注、分工、协同”等抽象词改成实体动作：旧器件被拿走；人从母体空间走向新主体；多个方案里一个被推到中央；信息从设计方交到制造方；分散站点依次接通。若只能想到“大字出现、三卡飞入、背景轻推”，说明尚未完成语义翻译，返回导演理解，不急着生图。

一个段内可有多个口播分句，但保持同一空间与主物件。推荐动作节拍是`建立空间→物件进入/接触→关系改变→结果稳定可读→旧层让位或退出`。节拍并非固定秒数，按本人真实录音、阅读时长和画面对象决定。**同一时刻只设一个最强焦点**；辅助物可以反应，但不能与主动作等强。上一句的纸片、卡片和字不能因为技术上容易就一直留到下一句。

## 画面构建

- **基底**：有语境的深蓝空间、真实桌面、工厂、地图或校园；纹理与纸边只建空间，不承担未核事实。不要复用同一张背景到全片。
- **中景语义主体**：写实摄影质感的人物、器件、纸页、校门、课表等。要运动的主体应可独立移动或至少有清楚的图生视频动作生命周期。
- **前景物理证据**：胶带、撕边、夹子、旧纸、模切边与真实阴影，用于说明“这些东西在同一个场景里发生接触”，而非为了把画面塞满。
- **关系线**：暖金线只在有来源、传递、路径、时间或责任交接时出现。每条线必须回答从谁到谁、送了什么、先后次序；不能当常驻灯带。
- **提示色**：冷蓝可标信息/设计，暖金可标接通/结果，砖红仅在冲突、排除或风险节点短时出现。颜色与对比从本片`design.md`派生，不机械照抄固定HEX。
- **文字**：中文、数字、年份、校名、政策和可核图表全部本地排版/真实原件；对象标签贴紧其物件，不能漂浮在空场。大字仅用于确有价值的章节开门、关键数值或结论落点，字幕保持手机安全区和停留时间。

图生视频可负责真实人物、手、工厂、桌面与空间动作；`vox_layered_broll`可负责纸层物理运动；`native_mg`负责准确文字、数学换算与数字关系；真实公告走`official_evidence`，有来源图表走`sourced_chart`。复杂镜头用原有`hybrid`，逐拍写明谁先接管、谁退到后景。不要同时把一张全合成生图、三个原生卡片、一张真实截图和字幕都堆在前景。

参考片的成片价值在**连续运动的因果链**，不只是最终单帧构图。对适合图生视频的语义群，起始帧应是动作尚未完成的状态，结尾帧是结果落稳的状态；提示词写清谁接触谁、物件怎么受力、焦点何时交给下一个物件、环境如何响应、旧层如何退出。模型输出若只是整幅画轻推、首尾溶解或物件融化，即使两张静帧都好看也要退回。准确字和数字可以在视频运动验收后本地贴合已有物件，但不许用漂浮字卡来补救缺少主体动作。Google Flow等手动渠道只能先交首尾帧与逐拍提示词；拿到牧之回传的真实MP4后才能完成动态验收。

## 可迁移的四种解释机制

| 口播任务 | 物理画面设计 | 错误替代物 |
|---|---|---|
| 从旧办法到新办法 | 旧器件被拿开，新器件接触同一接口，环境产生可见反馈 | 旧/新两张卡左右滑进 |
| 来源与分支 | 人/物从母体空间出发，路径按口播顺序连到新主体 | 一排Logo同时亮 |
| 承诺与实际交付 | 宣传物在前，翻开露出日历或执行者，责任线落到实际交付人 | 问号、空钱包、三句结论 |
| 责任或产业分工 | A的输出沿一条可追线抵达B，B开始工作，结果再交给C | 多个孤立图标和装饰箭头 |

例如考研课时换算：用户口播“同样写20课时，实际可能少5小时”时，先让真实课表落在桌面，定位合同里的`20课时`；秒表随后成为主视觉，走完一次`45分钟×20`；本地数字落成`15小时`，再让`比20小时少5小时`作为单一结论留下。若口播下一句转向合同核查，则差额纸条压进合同页，不能让课表、秒表、课堂照和四张信息卡一同残留。原创建议图只用于锁材质/空间；正式镜头应分别生产课表、秒表、阴影、教室与连线图层。

## 与原有动画库及图生视频怎样分工

在导演前原有`visual_route`中按语义选路线；涉及准确数据不因风格转入纯图生。对关系链、时间轴或证据放大，仍从原镜头库索引检索动作候选，再把它们改造成同一档案空间内的可触摸物件。可重点查`timeline-travel`、`depth-layer-moves`、`ring-diagram-annotation-reveal`和`scanline-annotate-focus`，但候选名不等于已选对镜头。图生镜头若要接本地组件，必须在`design.md`与故事板写明首尾状态、可用动作窗口、字和光路由谁做；不能让生成模型负责精确中文。

建议先完成一段难镜的有声动态分镜，再做高风险小样。检查的不是“纸张像不像”，而是观众关声后仍能大致看懂关系、开声后每个动作落在对应口播、下一语义进来时旧层已让位。手机端实际阅读、遮挡/阴影和完整退出是明确验收项。

## 不能照抄的源片问题

- 源片的画面生成标识、作者/平台水印、录屏通知与播放器控件不能进入我们的视频或模板。
- 源片大量小Logo、细英文与无来源曲线在手机上不可读；只借“来源分叉/双方对峙”的机制，具体文字和数值回到真实证据。
- 暗蓝、金光与纸片不是免责外衣。没有语义对应、只是完整母图推拉/字幕换词，仍按原产线PPT感否决。
- 不能把参考片里的历史人物、商标、书封或第三方影像打包进公开插件；原创应用图也不得被误称为用户已批准的正式画风。
- 模型生成的可读中文、数字和“官方材料”都不作事实证据；新增教育判断需按本片真实来源核实。
