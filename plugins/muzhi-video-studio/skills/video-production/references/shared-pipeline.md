# 不露脸知识口播：跨风格共用流程

这份只管生产次序和边界，不规定纸张、插画、颜色或镜头数量。项目已完成的步骤按真实回执继承，不为套流程重做。

1. **内容判断**：确定学生会问什么、这一条能给出什么判断、依据和条件、观众看完能做什么；区分事实、推断和转化表达。未锁稿可讨论，已锁稿与本人录音不擅改。
2. **导演前分路**：先完整理解真实 SRT 的论点、条件、否定、数字、例子与回调，再分真实动作、知识解释、官方证据、数据图表、实拍或混合路线。来源和可读文字的责任人先定；新片解释镜头在外部 Agent Motion 已安装且具有本项目使用依据时，按[接入合同](agent-motion.md)评估案例库，保留原`visual_route`。选例须落到实际动作和有声样片时码；未安装、缺使用依据或不适合就记录原因，继续 Shotcraft 或原创机制，不机械分配镜头数，也不让可选后端阻塞默认流程。用户明确指定只用该后端时报告其缺口，不擅换。旧项目不自动迁移，已确认镜头不重做。
3. **设计和样片**：`design.md`写本片风格、空间/材质/字体/色彩、视听节拍、每镜起终状态和供应商。Agent Motion 只执行选定镜头的动效，不从上游套画风或真人抠像；确需图生的真实动作仍由本片已选渠道（如H3）负责。本片最难段先出真实有声动态样片，逐时码看动作与口播是否互相解释。风格新颖不等于样片通过。
4. **生产和合成**：每个镜头有来源、渠道、任务ID、输入和结果哈希、原始媒体时长与状态。对图生失败仅返工受影响镜；外部动效也只返工选定段与相邻衔接。03维护唯一时间线，合成以本人真实口播为母钟，BGM和图生源声音不得串入。
5. **质量和交付**：看动态连续性、人物/手/道具、字幕逐字与手机安全区、证据来源、颜色风格、音频响度、封面裁切、三平台包。记录代理自检、用户认可、06品牌与07技术独立验收各自的真实范围，不能互相代签。
6. **发布和回流**：发布要有本轮授权；排期不等于已发。真实平台编号与作品数据回到原项目复盘，作为后续选题和风格改进依据。

同一项目可改图生渠道、可加新创意、可局部返工，但不借此解锁旧稿、改声音、清空费用台账或把试验风格变成默认。若影片有具体品牌标准，以本品牌最新已核`design.md`和批准资产为准。
