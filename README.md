# 牧之远见·视频创作工作室

不露脸讲知识，最难的常常是录完音以后：这一句该给观众看什么？这个 Codex 插件会和你一起读文稿、挑资料、想镜头，再把选好的画面做成一段能修改的试片。它能帮忙找素材和安排动作，事实、画风和最后好不好看，仍由你一起把关。

你可以继续已锁定的杂志插画项目，也可以为新片选“档案电流拼贴”。两种风格共用来源、声音和交付底线，不强迫所有片子长成同一种样子。

## 它会怎样帮你把话讲清楚

假如口播提到一条官方要求，画面不能只放一张模糊的网页。你可以让 Codex 先找到原页，带观众走到关键位置，再把需要读的完整句子放大。下一句开始解释时，上一处高亮先退下去，观众不用同时盯两块字。

要讲时间和数量，它会提醒你先核单位和口径，再设计数值、图形一起变化的镜头。比如“两小时完整写题”和“四段各半小时回忆”，总时长相同，画面该让人看到的是结构不同，而不是凭空画一条越来越高的趋势线。

讲“一看就会，一写就卡”，镜头方案可以先安排书页打开，再遮住答案，给笔尖一次犹豫和起笔的动作。书、手和纸要用你有权使用的素材或自己选定的生成工具准备，再由项目画面代码把动作做出来；插件不会凭一张静图保证真人动作。你和 Codex 先定一个能改的镜头方案，做出最难的一小段，对上口播、字幕和手机画面，再决定要不要铺整片。

它可检索 157 张 Shotcraft 文字配方和 214 个样式线索。214 个样式都有过限定范围的观察，方便知道“能借什么、哪里别用”；**这不是 214 个现成的一键模板**。[镜头库说明](docs/SHOT_LIBRARY.md)讲得更细，[质量与验收](docs/QUALITY.md)留给需要检查实际画面的人。旧项目不会因为插件升级而自动重选风格、重录声音或改写已通过的镜头。

## 从一小段开始

在支持插件的 Codex CLI 中安装：

```bash
codex plugin marketplace add JasperMZ-Zcy/muzhi-video-studio
codex plugin add muzhi-video-studio@muzhi-video-studio
```

新开任务后，可以这样说：

> 用视频创作工作室做一条不露脸知识口播。我有定稿和有权使用的录音，先帮我判断这段话需要观众看见什么，再推荐风格和一小段试镜。学校原文与我的解释要分开，预算和外部工具先对齐。

没有录音，也可以先用包内的小例子试一试它怎样找镜头、写方案。这一步不会假装生成一条视频。怎么运行写在[快速开始](docs/GETTING_STARTED.md)；做自己的片子，还需要你的授权素材、可用的视频工具，以及逐镜看画面、听声音。

插件不带模型、账号、API 密钥或付费额度，不会替你购买服务、上传素材或公开发布。Agent Motion 是可选外部后端，需你另行取得源码、环境及适用许可；没有它，Shotcraft 配方与本地原创机制仍可用于选镜。渠道说明见[PLATFORMS](docs/PLATFORMS.md)，隐私与素材边界见[安全说明](docs/SECURITY.md)。
