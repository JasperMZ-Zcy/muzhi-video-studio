# 牧之远见·视频创作工作室

你可以从一个视频想法开始，也可以带着已经确认的口播来制作。同一个 Codex 工作室有两个主入口：`content-planning` 陪你讨论题目、受众、平台、观点和说话方式，稿子确认后再交给 `video-production` 处理本人录音、字幕、导演和画面。讨论可以反复修改，制作会保留原件和已批准版本；事实、表达和最后好不好看，仍由你一起把关。

你可以继续已锁定的杂志插画项目，也可以为新片选“档案电流拼贴”。两种风格共用来源、声音和交付底线；旧片不会因为插件更新而自动改稿、换声、换画风或重做已通过镜头。

## 它会怎样帮你把话讲清楚

假如口播提到一条官方要求，画面不能只放一张模糊的网页。你可以让 Codex 先找到原页，带观众走到关键位置，再把需要读的完整句子放大。下一句开始解释时，上一处高亮先退下去，观众不用同时盯两块字。

要讲时间和数量，它会提醒你先核单位和口径，再设计数值、图形一起变化的镜头。比如“两小时完整写题”和“四段各半小时回忆”，总时长相同，画面该让人看到的是结构不同，而不是凭空画一条越来越高的趋势线。

讲“一看就会，一写就卡”，镜头方案可以先安排书页打开，再遮住答案，给笔尖一次犹豫和起笔的动作。书、手和纸要用你有权使用的素材或自己选定的生成工具准备，再由项目画面代码把动作做出来；插件不会凭一张静图保证真人动作。正式批量制作前，同一份网页导演板会逐镜放上接近成片的真实关键帧、对应原话与可听的本镜声音；你可以逐镜提出修改，改好后确认整版。需要看连续动作才能判断的镜头，还要有短预演或明确标为待完成。导演板批准不等于成片已通过。

它可检索 157 张 Shotcraft 文字配方和 214 个样式线索。214 个样式都有过限定范围的观察，方便知道“能借什么、哪里别用”；**这不是 214 个现成的一键模板**。[镜头库说明](docs/SHOT_LIBRARY.md)讲得更细，[质量与验收](docs/QUALITY.md)留给需要检查实际画面的人。旧项目不会因为插件升级而自动重选风格、重录声音或改写已通过的镜头。

## 从一小段开始

在支持插件的 Codex CLI 中安装：

```bash
codex plugin marketplace add JasperMZ-Zcy/muzhi-video-studio
codex plugin add muzhi-video-studio@muzhi-video-studio
```

只有想法、还没定稿时，可以这样说：

> 用牧之远见视频创作工作室的内容入口，陪我讨论这条片讲给谁、放在哪个平台、我真正想说什么。先给我一个有依据的方向，我们可以继续改，暂时不要制作视频。

已有确认稿和本人录音时，再进入制作：

> 用视频创作工作室制作这条不露脸知识口播。我有确认稿和有权使用的本人录音。保留原件，先给我听清理后的候选音轨；我确认最终声音后，你再校对字幕和时码、做逐镜导演板。图生视频和配乐要先和我确定这条片的方法，费用与外部工具按实际能力核。

没有录音，也可以先用包内的小例子试一试它怎样找镜头、写方案。这一步不会假装生成一条视频。怎么运行写在[快速开始](docs/GETTING_STARTED.md)；做自己的片子，还需要你的授权素材、可用的视频工具，以及逐镜看画面、听声音。纯代码配乐可以按本片旋律、节奏、段落和有限程序音色写出小样；你只需听它放进画面和口播后是否贴片、遮声，不用提供 BPM 或给音乐做专业评分。

插件不带模型、账号、API 密钥、付费额度或可任意复用的影片素材，也不会替你购买服务、上传素材或公开发布。可选本地转写只用你自行安装的 `faster-whisper` 与本片指定的已有模型快照，离线给草稿；机器识别结果仍由制作助手按最终音轨校对。图生供应商、AI音乐和外部后端也须逐片核能力、费用与许可。Agent Motion 是可选外部后端，需你另行取得源码、环境及适用许可；没有它，Shotcraft 配方与本地原创机制仍可用于选镜。渠道说明见[PLATFORMS](docs/PLATFORMS.md)，隐私与素材边界见[安全说明](docs/SECURITY.md)。
