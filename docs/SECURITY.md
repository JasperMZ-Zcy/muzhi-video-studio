# 安全与隐私

## 包含与不包含

这个公开包包含工作流说明、模板、校验器、项目内状态脚本、规则目录、原创图示，以及下述已核的少量公开展示样例。双入口、音轨处理、字幕检查和代码配乐工具不附送真人录音、模型、账户或可直接用于任意影片的素材。除此之外，不应把下列私人或运行时材料打入包：

- API key、cookie、token、账号、密码、浏览器会话或本地连接配置；
- 未批准公开的录音、个人照片、原始视频、学生资料、项目导出物或发布回执；
- 本机绝对路径、私有工作台地址、私有仓库地址或未公开的品牌资产；
- 任意供应商的余额、额度、合同或支付信息。

根目录的 `.gitignore` 忽略常见密钥、环境文件、运行时 artifacts、媒体、导出物和 Python 缓存。提交前仍应人工检查暂存内容；忽略规则不能替代审查。

仓库原有的 `docs/assets/showcase/` 是**明确的展示例外**：三张已交付知识口播的定格图及旧作数据截图，按牧之此前对公开自己作品与后台成绩的授权保留；档案电流拼贴的定格图和约五秒原生试镜，按2026-09-24的公开风格展示授权保留，试镜里的金线时序瑕疵仍如实说明。三张作品定格的来源时点与SHA在[`sources.json`](assets/showcase/sources.json)，数据截图的来源记录在[`performance-source.json`](assets/showcase/performance-source.json)。这些是既有公开作品／风格方向的展示，不是插件给新项目自动提供的通用素材，也不代表新版本的效果或正式镜头已验收。仓库原有 MIT、Shotcraft Apache-2.0 与各素材实际来源许可继续分别适用；本页不另改许可，也不替任何第三方素材扩权。

镜头库如附带原例的**文字观察**，只保留样式 ID、观察范围和可公开来源线索。研究原片、抽帧图、个人项目计划、学校截图与本机绝对路径都不应随包。第三方文字卡的 Apache-2.0 授权不能代替视频、字体、纹理或另一后端的使用许可；对外打包前逐件检查权利、隐私、脱离原项目后的可用性和事实语境。

## 工具权限边界

- `project_state.py`、`provider_router.py` 和 `generation_ledger.py` 只写入使用者指定项目目录下的 `artifacts/` 状态文件。
- 录音处理只在使用者指定项目内生成新的解码/清理副本与哈希回执，原录音保留；只有本人真实试听确认后，才能把该候选作为正式音轨继续。字幕校对由制作助手完成，确认文字和时码不能凭ASR草稿或差异摘要自动填成通过。
- 本地ASR需要使用者自己安装可选依赖并明确提供已存在的模型快照；就绪检查不下载模型，也不证明转写质量。不能把私人工作区的转写器、模型路径或授权素材写进公开包当默认能力。
- 代码配乐仅从本片谱和有限程序音色生成项目内新音频；AI音乐及图生渠道仍各自受实际连接、许可与费用授权限制。生成WAV或登记方法不等于使用者已认可贴片效果。
- 供应商路由不会读取凭证、访问 URL、执行 `tool_ref`、上传媒体或调用 API。
- 成本台账不会预订额度或阻止绕过它的直接供应商调用；它只在实际被调用时记录留额与回执。
- `package` 只复制明确列出的项目内文件，拒绝父目录跳转、符号链接穿透、秘密样式文件和不同内容的同名覆盖。

因此，插件是本地执行纪律，不是供应商级安全隔离、支付防火墙或账号权限系统。

## 使用者责任

1. 只在你有权处理的项目目录、素材和账号中运行命令。
2. 将凭证保留在你选择的安全连接或系统密钥存储中；不要把它们写进项目、提示词、台账、日志或插件目录。
3. 对新增付费生成、重试、账号变更、公开上传、定时发布和删除操作取得相应的明确授权。
4. 生成后检查输出媒体、来源许可、事实表述与平台的 AI 内容标注要求。
5. 如果意外提交过敏感文件，先撤销／轮换暴露的凭证和访问权限，再按平台与组织流程处理历史记录。

## 报告问题

请不要在公开 issue 中贴出密钥、完整媒体、学生资料或账号回执。用可复现的最小描述说明：使用的脚本版本、命令类别、预期行为、实际错误和已脱敏的结构信息即可。
