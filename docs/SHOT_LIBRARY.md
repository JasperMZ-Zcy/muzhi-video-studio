# 知识解释镜头库：先选关系，再选动效

同一句口播，可能需要一张原始资料安静停读，也可能需要对象真的移动、条件保持未知，或让一组数同时改动柱形、轴和读数。镜头库的任务是帮你比较这些办法。它不会看见一段文字就自动挑出“正确镜头”。

## 这些数字各指什么

本地有 **157 张 Shotcraft 文字配方**，对应 Gallery 的 **214 个 style**。我们逐份读过固定提交中的相关源码，并对 214 个 style 各留下至少一条有界视觉观察：四批原例有 208 张时序图，每张抽取 12 个原视频源时间点；少数 style 另有浏览器播放观察。同一 style 有两位观察者时，记录可以有两条，**不能算成两个新样式**。

这份学习能让你在 `read` 中看到具体动作链、控制线索、换稿要提供什么、哪里不适用。它不代表 214 段视频都经过完整正常速度观看，也不证明 Gallery MP4 就是固定提交 TSX 渲出的，更不代表 214 个本地可执行组件。Shotcraft 原视频、demo JSX、字体、纹理和我们的研究抽帧都不随插件打包。

例如，`sheen-sweep` 的 12 点样帧没有清楚捕到可辨的流光，不能因名字就把扫光记为动态已证；`shot-transitions-5` 当前抽帧看见的是卡片堆进入周报文档，和固定源码笔记里的同长页读窗虚焦接力不能强认同版。观察记录是帮助你选用和拒用的材料，不是宣传数字。

## 从一句话走到一个镜头

先把原话读完整。抓住作者的主张、引用、否定、条件、数字口径和后文回扣，想清观众看前可能误会什么、看后该知道什么。然后分配画面责任：

| 观众必须看见 | 常见承载方式 | 不能偷换成 |
| --- | --- | --- |
| “这句话从哪里来” | 有权原页、来源身份、完整读窗与准确摘录 | 只有终点截图却演出未发生的点击 |
| “先满足什么，结论才成立” | 独立证据和明确的未满足/未知/已满足状态 | 卡片碰一下就自动亮“成功” |
| “两个数怎么比” | 同口径真值、单位、分母、零基线及同钟读数 | 不同年份或拟招/录取混成一条趋势 |
| “同一东西变到了哪” | 稳定对象 ID、原槽和目标槽、一次实例 | 旧物未退却另复制一件 |
| “该看哪一处” | 焦点交棒、相机/页面真实位置与停读 | 全页小字在背景闪过 |

真实来源负责事实身份；可控字图负责准确中文和数字；人物、纸张或器物负责动作。它们可以同镜组合，但要写清主次和旧焦点何时退出。只想引用原句时，安静停读往往比多一道飞入更好。

在插件目录可先试原候选入口：

```bash
python scripts/resource_handoff.py search-receipt 列表 画布 --per-source 1
python scripts/resource_handoff.py search-receipt 同一对象 迁移 --per-source 1
python scripts/resource_handoff.py read --ids semantic_action:RowCanvasTransfer
```

两组词可能找到同一候选。泛词零结果时，换成“对象如何变、观众要看见哪一步”的关系词再查，别编造候选或立即断言库无能力。检索命中只说明找到了原件；选中后要读当前来源和 SHA、明确采用与弃用理由，再把适配代码、素材和预览证据写进原计划。旧项目已有锁定时，只检查这次授权返工的段落。

## 可改的本地机制，按适用范围用

下面是源码能力，不是固定画风或自动成片按钮。每一项都需要本片的 props、项目包装镜、授权素材和同版编码帧；纯函数还需要消费者把计算结果真正画出来。

| 机制 | 能帮上什么忙 | 重要边界 |
| --- | --- | --- |
| `RowCanvasTransfer` | 同一条列表项离开原槽，落到画布新槽 | 稳定 ID 与实际视觉节点由项目提供；不替内容自动归类 |
| `FocusHandoff` | 两件已绑定的视觉层错峰退焦、收焦 | 焦点交换不等于真页面导航或事实成立 |
| `PolarContourMorph` | 等长径向采样的闭合单轮廓形变 | 有孔、C 形或任意 SVG 不适配 |
| `CountParticleFill` | 以明确的整数“每粒单位”筑出离散数量 | 不可整除、未知分母或“每粒≈多人”时不能冒个体 |
| `SceneCoordinate` | 让相机、目标框与光标共用坐标，计算停滚 | 只是纯函数，不取网页、不提供可读源图 |
| `ChartGeometry` | 让堆叠总数，或折线已画段/端点/读数同源 | 不提供真数据或完整图表场景 |
| `PathArc` | 区分贝塞尔参数时刻与实际走过的弧长 | 不自动匀速、转向或处理碰撞 |

完整官网查找、手机对话、时间带和轴联动等场景仍要在具体项目里绑定自己的来源页、准确字、视觉层和时间线；本公开包不附带内部试片的图片、录音或项目包装镜。一个可改的零件只能领取自己实际做到的动作，不能靠名字承担整段原意。要表现“进站找文”，源页序列、实测点击点、加载/停位和最终完整句子的近读都要另行提供，单个裁窗也不能代替导航过程。

## 许可和验收

[video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) 的文字卡按 Apache-2.0 与署名保留；本仓库原创适配代码按本仓库相应许可。上游媒体、demo、第三方字体和纹理各有自己的权利状态，不因文字卡可引用就能拿来给客户出片。Agent Motion 是另一套可选外部工程，其上游分析与源码不在本包内；[第三方说明](../THIRD_PARTY_NOTICES.md)列了边界。

给新文案换词、换数还不够。真正的复用至少要看到两种不同语义输入如何改变起点、运动、终点和读点，并检查一个会让机制失效的反例；最后在编码帧、正常速度和手机尺度上看观众能否复述原意。[质量与验收](QUALITY.md)把计划态、实际媒体和人工判断分开。
