# 知识解释镜头库

这是一套给知识口播使用的镜头参考。插件保留 **157 张镜头配方** 与 **214 种动效样式索引**，帮助你把比较、因果、流程、资料、证据和有来源数据讲成观众能跟上的画面，少花时间从零想镜头。

## 怎么用

把已确认的口播、相关资料和想要的画面感觉告诉 Codex。已有 `design.md` 就一起交给它；还没有，就让它根据沟通整理，你不需要自己写设计文件。导演板前，Codex 会按段落选画面路线。

| 口播需要讲清的事 | 更合适的画面 |
| --- | --- |
| 人物动作、环境变化、情绪表演 | 图生视频或已有真实素材 |
| 比较、筛选、因果、步骤、概念 | 知识动效或纸艺分层图解 |
| 院校招生简章、政策条款、真实表格 | 原始页面的局部放大、高亮与解释 |
| 有来源的数据变化或构成 | 标明口径、年份、对象、单位与出处的图表 |

图生画面和知识动效共用同一份 `design.md`。先确定本片是杂志插画还是档案电流拼贴，再把选中的镜头配方改造成那种风格；两种风格不共用一套固定人物或纸张画法。色板、字体、材质、构图、字幕槽和运动节奏要在本片内部统一。设计改动后只复核受影响镜头，已经锁定的录音、素材和通过内容不自动重做。

## 先记住这些边界

- 配方服务理解，不要求每句话都加动效，也不能压缩中文的阅读时间。
- 214 种样式是可检索的样式线索，不代表全部已经在本地渲染通过，也不代表会自动适配你的文案、声音或屏幕比例。
- 学校名、政策、表格、精确文字和数字由真实材料承载。可以放大、高亮并解释，不能用图生模型造一张像官方的截图。
- 镜头库不附赠账号、模型额度或付费服务，也不保证播放量。最终效果应按你的内容、审美、工具和预算沟通调整。
- 它不改旧片。只改封面或继续已有项目时，沿用原有范围与锁定内容。

## 来源与改编说明

镜头配方参考开源项目 [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) 的 Apache-2.0 贡献。插件保存固定来源的文字卡和样式元数据，用作镜头思路参考。它没有把上游预览视频、音频、完整工作台或示例数据打包进来。

本插件把其中少数动作机制改写成了本地知识解释组件。它们不是对上游全部内容的原创声明，也不表示每一种上游变体或未来项目都已经验收通过。

需要查看镜头库的详细选择和核验边界时，可在插件目录运行以下命令。

```bash
python scripts/shotcraft_catalog.py validate
python scripts/shotcraft_catalog.py search 比较
python scripts/shotcraft_catalog.py search 证据
```

这些命令只读本地参考，不会下载媒体、提交生成任务或渲染视频。
